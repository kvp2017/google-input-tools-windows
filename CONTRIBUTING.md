# Contributing

- Keep the transliteration engine platform-neutral.
- Put Windows-specific Text Services Framework code under `src/windows-tsf/`.
- Add a test for every transliteration rule or dictionary change.
- Tamil language data must include provenance and a review status.
- Do not add third-party dictionaries, fonts, models, or code without recording their license.
- Use UTF-8 source files and preserve Apache-2.0 notices.
- Never commit signing keys, certificates, credentials, or personal vocabulary.
- Label experimental language rules clearly until reviewed by fluent speakers.
